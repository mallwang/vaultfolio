# Personal Finance Management

A personal finance management web application — frontend, backend, and database, packaged and
hosted as Docker containers.

## Status

This repository is in initial setup. Architecture and governance are defined in the project
[constitution](.specify/memory/constitution.md); the technology stack (frontend framework, backend
language/framework, database engine) has not yet been chosen.

## Development process

This project uses [Spec Kit](.specify/) to drive development:

1. `/speckit-constitution` — project principles and constraints (done)
2. `/speckit-specify` — define a feature
3. `/speckit-plan` — plan its implementation
4. `/speckit-tasks` — break the plan into tasks
5. `/speckit-implement` — implement the tasks
