What this mockup covers

  • FR-001 / FR-002 / FR-003: screen 1 (offer, explicit consent, nothing starts before it), screen 2 (progress per page, cancel).
  • FR-006 / FR-007: screens 3 and 4 (notice in the preview, badge in the saved list).
  • FR-005: screen 3 keeps the existing failing-check handling and correction fields.
  • FR-009 / FR-010 / FR-011: screens 5 and 6 (request offer, "recognised automatically" notice, low-confidence marks, removed values including a misread IBAN).
  • FR-008 / FR-013 / FR-014: screen 7 (same message when declined, cancelled or no text; extra hints for the page limit and an unavailable engine).

Not in the mockup

  • Wizard steps 1 to 3 of the request flow (unchanged from spec 033), German texts, e-mails.
  • Visual language approximates the PrimeNG Aura preset, as in the 032 and 033 mockups.
