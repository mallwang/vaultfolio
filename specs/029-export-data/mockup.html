What this covers

  • US1 (P1): the Export split-button ("info" severity) to the left of "Add holding", its format menu (JSON/CSV/Excel/PDF with distinct icons), and the PDF's charts + table + infobox (FR-001–FR-005, FR-003a).
  • US2 (P2): the same control reused verbatim in position/behavior on the other five features — shown here structurally via the shared markup/classes, not as five separate screens.
  • US3 (P3): "Export my data (optional)" in the Settings danger zone, wired to a real action instead of the current no-op placeholder (FR-010–FR-012).
  • Language switching for headers/labels/PDF text (FR-006), via the "Language" toggle.

Not shown here (out of scope for this mockup)

  • The five other features' own screens — each adopts the identical control/menu/PDF shape shown here, scoped to that feature's own data and infobox text (FR-008/FR-009); mocking up all six would only repeat this same layout.
  • Empty-state exports, partial-export-failure messaging, and the exact archive/folder contents (FR-014, FR-015) — data/logic behavior, not layout.
  • Real chart rendering — the conic-gradient circles stand in for the actual ECharts distribution charts already used on the Holdings page.
