# market-data

**Reserved, intentionally empty.** No market-data provider is selected or wired here —
see the constitution's open `TODO(MARKET_DATA_PROVIDER)`. This library exists only to reserve
the module boundary (`scope:domain`) that a future feature will fill in when live market-data
lookups (prices, ETF composition) are implemented, per Principle I (Library-First) and the
Product Scope's External Market Data rules.
